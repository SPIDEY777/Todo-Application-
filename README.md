# Todo Application

A simple, lightweight **Todo Application** built with Spring Boot, Thymeleaf, MySQL, and Bootstrap. This project demonstrates basic CRUD operations for efficient task management.

## 🚀 Features
* **Create Task:** Quickly add new tasks to your list.
* **View Tasks:** Automatically displays all stored tasks from your database.
* **Toggle Status:** Mark tasks as "Done" (with strike-through effect) or "Undo" with a single click.
* **Delete Task:** Remove tasks easily with the delete functionality.
* **Responsive Design:** Styled with Bootstrap for a clean, mobile-friendly interface.

## 🛠️ Technologies Used
* **Backend:** Java, Spring Boot, Spring Data JPA
* **Frontend:** Thymeleaf, Bootstrap 5.3
* **Database:** MySQL
* **Build Tool:** Maven

## 📋 Prerequisites
* JDK 17 or higher
* MySQL Server
* Maven installed
